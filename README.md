# Your research portfolio

## Files
- `index.html`: the design and layout. You rarely need to touch this.
- `content.js`: **all your text and links**. Edit this file to update the site.
- Put images (plots, photos, CV PDF) in this same folder.

## Editing
1. Open `content.js` in any text editor (or click the pencil icon on GitHub).
2. Change text inside the "quotes", or add entries to the lists (`experience`, `education`, `publications`, `gallery`, `achievements`, `highlights`).
   Each commented-out line in the file is a ready-made example: remove the `//` and edit it.
3. Empty fields are hidden. While `showEmptyHints` is `true` you will see dashed "add me" boxes where content is missing; set it to `false` before sharing the site.
4. Be careful with punctuation: every item in a list needs a comma after it, and a text field like `statement` must be ONE string in quotes. A stray quote or comma can blank the whole page.

## Updating the live site (GitHub Pages)
1. Open your repository, click the file (for example `content.js`), then the pencil icon.
2. Edit, then click **Commit changes**. The site refreshes in a minute or two.
3. To replace a whole file, use **Add file → Upload files** and upload the new version with the same name.
